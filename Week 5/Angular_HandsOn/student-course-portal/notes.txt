Hands-On 1 — Task 1: Notes on generated Angular project files
================================================================

angular.json          - Workspace configuration: defines the project(s), build/serve/test
                         architect targets, file paths, and build budgets.

tsconfig.json          - Root TypeScript compiler configuration shared across the app,
                         specifying strict type-checking and Angular compiler options.

tsconfig.app.json       - TypeScript configuration specific to the application build
                         (extends tsconfig.json, points at src/main.ts as the entry file).

package.json            - Lists npm dependencies (Angular packages, RxJS, zone.js) and
                         devDependencies (Angular CLI, TypeScript), plus npm scripts
                         (start, build, test).

src/main.ts             - The application entry point. Bootstraps the standalone
                         AppComponent using bootstrapApplication() and the appConfig
                         (providers for router, HTTP client, etc.).

src/app/app.config.ts   - Standalone application configuration: registers global
                         providers such as the Router and HttpClient (replaces the
                         old AppModule in NgModule-based Angular).

src/app/app.component.ts - The root component of the application; hosts the
                         <app-header> and <router-outlet> in its template so routed
                         pages render inside it.

src/index.html          - The single HTML page served to the browser. Contains the
                         <app-root> tag where Angular bootstraps the application.

Notes on angular.json budgets
------------------------------
Under architect > build > configurations > production > budgets, the "initial" budget
controls the maximum size of the initial JavaScript bundle:
  - maximumWarning: 500kb — the CLI prints a build warning if the initial bundle
    exceeds this size.
  - maximumError: 1mb — the CLI fails the production build if the initial bundle
    exceeds this size.
These thresholds catch bundle-size regressions early, before they impact real users.
