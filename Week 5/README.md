# Week 5 — Angular / React

## Contents

- **`Angular_HandsOn/`** — Angular v20 "Student Course Portal" project covering Hands-On 1–5
  (project setup, components, binding, lifecycle hooks, directives, pipes, template-driven &
  reactive forms). Continues in `Week6/Angular_HandsOn`.

- **`react-apps/`** — 9 independent Create React App projects covering ReactJS-HOL exercises 1–9:

| # | Folder | Exercise |
|---|---|---|
| 1 | `01-myfirstreact` | React environment setup with create-react-app |
| 2 | `02-studentapp` | Class components (Home, About, Contact) |
| 3 | `03-scorecalculatorapp` | Function component with props (CalculateScore) |
| 4 | `04-blogapp` | Lifecycle hooks — `componentDidMount`, `componentDidCatch` |
| 5 | `05-cohortdashboard` | Styling with CSS Modules & inline styles |
| 6 | `06-trainersapp` | React Router — navigation & routes |
| 7 | `07-shoppingapp` | Props, defaultProps, `ReactDOM.render()` |
| 8 | `08-counterapp` | State & event handlers (entry/exit counter) |
| 9 | `09-cricketapp` | ES6 `map()`, arrow functions, destructuring |

## Running a React app

Each app under `react-apps/` is independent:

```bash
cd react-apps/01-myfirstreact
npm install
npm start
```

## Running the Angular app

```bash
cd Angular_HandsOn/student-course-portal
npm install
npm start
```
