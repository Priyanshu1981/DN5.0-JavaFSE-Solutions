# GIT Hands-On 1–5 (Week 6)

Command-by-command walkthroughs for each Git hands-on lab. These are Git Bash
transcripts (not application code) — follow them in order against a real
GitHub/GitLab repository to reproduce each exercise.

| File | Covers |
|---|---|
| `01-git-setup-and-first-commit.md` | Git configuration, editor integration, first commit & push |
| `02-gitignore.md` (+ `.gitignore`) | Ignoring `.log` files and a `log/` folder |
| `03-branching-and-merging.md` | Creating a branch, committing on it, merging back to main |
| `04-merge-conflict-resolution.md` | Deliberately conflicting edits and resolving them with a 3-way merge |
| `05-cleanup-and-push.md` | Pulling remote changes and pushing the resolved history |
